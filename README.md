# aws-support-solutions

A collection of curated solutions created by AWS Support. Each solution addresses a
specific customer problem that AWS Support engineers encounter in the field, and lives
in its own directory grouped by category.

Solutions are self-contained: every directory has a README covering what the solution
does, how to deploy it, and how to clean it up.

## Available solutions

### Resilience

| Solution | Description |
|----------|-------------|
| [Guidance on Enhancing Resilience with DevOps Agent and Fault Injection Service](Resilience/guidance-for-enhancing-resilience-devops-agent-fis/) | An MCP server that recommends AWS Fault Injection Service (FIS) experiments based on DevOps Agent findings, helping teams design chaos engineering experiments to validate system resilience. |
