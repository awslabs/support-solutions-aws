## Reporting Security Issues

AWS is dedicated to the responsible disclosure of security vulnerabilities.

If you discover a potential security issue in this project, we ask that you notify AWS
Security. Please **do not** create a public GitHub issue.

You can report a vulnerability either through the
[AWS Vulnerability Disclosure Program](https://hackerone.com/aws_vdp) on HackerOne, or by
emailing [aws-security@amazon.com](mailto:aws-security@amazon.com) directly.

For more information, see
[AWS Vulnerability Reporting](https://aws.amazon.com/security/vulnerability-reporting/).

Thank you for helping us protect our customers.
